# Support SeedExpand

SeedExpand is MIT-licensed and its core functionality is free. Donations are optional, never required to unlock expansion, privacy or export.

Donations are not enabled. No receiving account or payment destination has been verified for this project. Until then, useful support means reproducible bug reports, accessibility feedback, code review, documentation and sharing the project.

The intended funding model is a discreet optional support link in the README and About screen. Do not add prompts during typing, recurring nags, paid privacy features or financial projections. GitHub Sponsors is a possible route; the maintainer must complete any applicable onboarding and approve a real destination before enabling it.

Reference: https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-personal-account
